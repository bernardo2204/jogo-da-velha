# Jogo da Velha

Jogo da velha (tic-tac-toe) para dois jogadores, no terminal, em Python.

- Tabuleiro desenhado em ASCII, atualizado a cada jogada
- Verifica vitória em linhas, colunas e diagonais
- Detecta empate quando o tabuleiro enche
- Valida a posição digitada e impede jogar em cima de uma casa ocupada
- Permite jogar várias partidas seguidas

## Como rodar

```
python main.py
```

## Arquivos

- `main.py` — laço principal do jogo
- `velha.py` — tabuleiro, verificação de vitória e a partida
